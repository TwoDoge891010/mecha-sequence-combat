# 原型启动脚本（归档）

> 一句话背景：一键拉起战斗体系原型编辑环境的 Windows 批处理脚本，2026-09-10 从桌面移入本项目归档，桌面不再保留副本。

## 这里有什么

| 文件 | 说明 |
| --- | --- |
| `启动 Axhub Make.cmd` | 一键启动脚本：拉起 53817 后台编辑服务 → 检查/启动 51720 运行时 → 轮询就绪后自动打开浏览器 |

## 怎么用

双击 `启动 Axhub Make.cmd` 即可。脚本做三件事：

1. `npx -y @axhub/make@latest --no-open --background` 拉起后台编辑服务（53817）。
2. `curl` 探测 51720；未运行则用最小化窗口启动 `npm run dev`。
3. 轮询 51720 直到就绪（最多约 60 秒），然后打开 `http://localhost:51720/`。

运行时跑在最小化的 `AxhubMake-Runtime` 窗口里，**关掉那个窗口即停止 51720**；53817 是独立后台服务，不受影响。

## 前提与约束

- 脚本内用 `cd /d` 定位承载工程（`.cmd` 定位外部工程的必要写法）；承载工程、原型源码位置、编辑器地址见 `docs/PROJECT-STATUS.md` 第 5 章。
- 脚本是 **GBK 编码、无 BOM、CRLF**，首行含 `chcp 936 >nul`。编辑时务必保持这一编码，改成 UTF-8 会让 cmd.exe 按字节错位解析、行被拆散。
- 依赖：Node/npm 可用、`curl` 可用（Windows 10 自带）。

## 想要桌面入口怎么办

不要再往桌面复制文件本体，**建快捷方式**指向本目录下的 `启动 Axhub Make.cmd` 即可；脚本真值始终只保留在这一份。
