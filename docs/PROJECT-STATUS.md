## 二、当前版本与真值口径

- **设计版本**：v0.8（战斗体系）。v0.9 仅用于新的赋能插件独立表版本号，不代表设计文本升版。

- **真值优先级**（因冲突时以此为准）：**原型 index.tsx（可运行实现）>** **`behavior`** **/** **`enhance`** **插件表 > HTML 正文 + 决策记录**；若非执行层语义，HTML 正文与决策记录最高。

- **竞品机制归竞品**：HTML 中「魔法工艺 → 赋能作用于下方所有技能」是**竞品**机制描述，**非本作**设定，不得据此推断本作赋能行为。

- **三插件语义（当前真值）**：

  - 行为插件：一卡一用，9 变体（3 稀有×3 槽），是技能与动画载体。

  - 中继插件：条件触发组件，行为↔行为间衔接，一拖 N，多分支不摊薄。

  - 赋能插件：**词缀**，只作用于所附着那张行为卡本身，不入树、不承担衔接，每卡 ≤2，载荷叠加，不分稀有度。

### 5.2 怎么启动（两条路，选一条）

- **一键（推荐）**：双击归档在项目内的 `sessions/原型启动脚本/启动 Axhub Make.cmd`（2026-09-10 起脚本归档在项目里，桌面不再保留副本）。它依次做三件事：拉起 53817 → 检查/启动 51720 → 轮询就绪后自动打开浏览器。运行时跑在一个最小化的 `AxhubMake-Runtime` 窗口里，**关掉那个窗口即停止 51720**（53817 是独立后台服务，不受影响）。
- **手动**：`cd E:\Projects\axhub-make-client` 后 `npm run dev`。Vite 插件会自动把 53817 一并拉起，无需另外执行命令。

### 5.3 怎么编辑

浏览器打开 `http://localhost:51720/`（会自动跳到编辑器），在侧栏选中 `combat-system-design` 条目即可。编辑器**写回的是工程内源码文件**（`src/prototypes/combat-system-design/`），不是导出快照——因此后续大改继续在同一处迭代，不要改用「打包成独立 HTML」的方式（那样会失去 axhub 编辑能力）。

### 5.4 环境约束（改启动/打包相关时必读）

1. **控制台代码页 936（GBK）**：中文 `.cmd` 必须以 **GBK 编码、无 BOM、CRLF 换行**写入，并在首行加 `chcp 936 >nul`。**不要**写 UTF-8 的中文 `.cmd`（cmd.exe 会按字节错位解析，导致行被拆散、报「'open' is not recognized」这类怪错）。
2. **Node 22 + Windows**：不允许直接 `spawn` `.cmd` 文件（CVE-2024-27980 修复后行为），必须 `shell: true`，否则必定 `EINVAL`。改 `vite-plugins/autoStartMakeServerPlugin.ts` 时注意：`shell` 要真正传进 `spawn` 的选项里。
3. **`@axhub/make` CLI（v0.6.21）**：不接受位置参数，**项目根取自当前工作目录**；支持 `--no-open` / `--background` / `--json` / `--port` / `--runtime-origin` 与子命令 `status` / `stop` / `open`。
4. 备份：改写前的原始启动脚本存于工具临时工作目录下的 `启动 Axhub Make.cmd.bak`（临时目录可能被清理，需长期留存请另行复制）。

### 6.3 设计原则速览

- **三维可编程战斗**：行为（技能载体）/ 中继（触发衔接，一拖 N，多分支不摊薄）/ 赋能（词缀，不入树，每卡 ≤2，载荷叠加）三类插件 + 序列插槽 + 机甲核心。
- **灵感源头**：BALDR SKY（可编程连段）、Bio-Prototype（架构参考）、传说法师（构装嵌入、连段窗口 0.35s、超限演出）。
- **四条核心机制**（详见 HTML 4.x）：① 状态值累计条——命中累计、满条施加、条随时间衰减（非概率）；② 热量值——积热/耗热，超限=复用基础槽形态放大；③ 中继效率由「触发条件苛刻度」定，条件越苛刻效率越高；④ 召唤物=定时引信——限时存在，销毁（到期/替换）为第 5 类中继触发事件。
- **命名规范**：插件四字工业风 `[属性/材质/形态前缀]+[工业动作后缀]`；引擎码 `BT_`（行为）/`EN_`（赋能）/`RL_`（中继，规划中）。
