# 核心 · 流派 · BD 组合设计（讨论稿 v0.1）

> **定位**：讨论稿，**不是真值**。真值仍以 `game-design-requirements.html` 4.8 + 三张插件表为准。
> **目标**：回答三件事——
> ① 这游戏能给玩家哪几种**不同的爽**；
> ② **核心**如何对一整类玩法产生质变（而不是加数值）；
> ③ 插件组合能拼出哪些**非显然的奇妙反应**（哈迪斯式转模的对应物）。
>
> 日期：2026-10-27 · 依据：行为表 v0.8（15 插件 / 45 行）、赋能表 v0.9（23 词缀）、中继表 v0.9（8 中继 / 24 变体）、HTML 4.8 / 4.9 / 05。

### 0.2 三个硬缺口（会直接卡住流派）

| # | 缺口 | 后果 |
|---|---|---|
| 1 | **标记无来源** | 全库没有任何行为插件或赋能词缀能「施加标记」；铭痕裂击是唯一联动插件，但打不出标记 → 死状态，整条处决流不成立 |
| 2 | **状态源极度不均** | 燃烧 1 源（炽燃斩）、失衡 1 源（重力轰拳）、感电 2、侵蚀 2、无状态 7 → 现在真正能成型的流派只有「纯物理」「感电/侵蚀」「燃烧（薄）」；失衡是单插件依赖 |
| 3 | **召唤只有 1 插件** | 一插件一用 → 浮游机炮只能进一棵树，另一棵树和超限都空着 → 召唤流无法成立 |

### 0.3 一处数据卫生问题

行为表序号 2 / 3 / 6 各出现两次（涡刃绞击 vs 雷矢链刺、重力轰拳 vs 侵蚀爪刃、浮游机炮 vs 索锚打击）。引擎 ID 不冲突，但策划查表会误读。建议统一重排 1–15，等本次设计方向定了再动表。

### 0.4 与哈迪斯的根本差异（必须先说清）

哈迪斯的爽，来自**局内随机抽取 + 双神祝福**：每一局都在赌「这次能不能凑出来」。
本作的爽，来自**局外编程 + 局内执行**：机器是玩家事先造好的，局内是把机器跑顺。

结论：**不能照搬抽卡式转模**。本作的「转模」应该是**预构筑时的组合发现**——玩家在构装界面自己找出「散射 + 电磁链锁 = 电网」这种化学反应，而不是局内祈祷抽到。

> 如果确实要做 roguelite 层（局内掉核心 / 掉词缀），那是**独立议题**，不要混进核心设计。见 §七 待拍板 7。

## 一、爽感五轴

先把「爽」拆成可设计的轴，而不是笼统说「打击感好」。

| 轴 | 核心爽点 | 输入特征 | 兑现方式（看得见/听得见） | 失败模式 | 天然支撑插件 | 天然反爽点 |
|---|---|---|---|---|---|---|
| **① 连奏 Flow** | 按键密度、无缝衔接、节奏掌控 | 高频、短前后摇、三键穿插 | 连段计数、卡点音效、命中停顿 | 无脑连点 → 疲劳 | 多重连刺、雷矢链刺、连击链动 | 中继 0.5s CD 让高频命中「空转」 |
| **② 核爆 Burst** | 蓄势、兑现、一发入魂 | 低频、高价值、需要铺垫 | 时停、屏幕震动、大数字 | 空大、被断、蓄力被躲 | 蓄力重斩、破韧重装、蓄势派生、临界引爆、超限 | 蓄力期间没有霸体 |
| **③ 织网 Weave** | 布局、自动运转、屏幕被自己填满 | 低频决策、高频观察 | 触发连线、脉冲、召唤物存在感 | 铺场慢、打不到人、视觉噪音 | 浮游机炮、涡刃绞击、公转/环绕、走时回路 | 自动触发「看不见因果」 |
| **④ 锁链 Lockdown** | 把敌人钉住、在窗口里倾泻 | 控制起手 → 窗口输出 | 失衡/定身动作、破防音效 | Boss 免控、抗性递进、窗口太短 | 重力轰拳、索锚打击、断稳、失衡爆破 | 失衡只有 2s，窗口太短 |
| **⑤ 赌命 Gamble** | 越危险越强、刀尖跳舞 | 主动放弃安全资源 | 低血警告、心跳音、红色滤镜 | 真的死了 → 挫败 | 熔炉核心、超频狂暴、钟摆 | 没有回血出口 = 劝退 |

**使用规则**：一个 BD 可以同时吃 2 轴，但必须**主副分明**。三轴以上 = 数值必然失控，且玩家说不清自己在玩什么。

## 二、核心设计

### 2.0 设计原则

1. 核心**只改写 1–2 条规则**，不做数值加成。
2. 数值只作为**代价**出现（耗血、降效率、加载荷），不作为卖点。
3. 每个核心必须能回答：「同一个插件装进这个核心，玩法变了吗？」答不上就不是核心，是饰品。
4. 核心不能拆掉支柱。跨树协作、中继专属触发、赋能不入树——这三条是身份，不能为了「爽」让步。

### 2.1 熔炉核心 · 过载（主：核爆 / 副：赌命）

> 完整机制、数值与五档局外升级见 [`熔炉核心-设计与局外升级-v0.1.md`](熔炉核心-设计与局外升级-v0.1.md)。

| 项 | 内容 |
|---|---|
| **改写规则 1** | **资源**：超限释放不再消耗热量，改为消耗 **15% 最大生命**（击杀返还 50%，2 杀封顶） |
| **改写规则 2** | **资源 + 门槛**：热量不再自然衰减；释放门槛降为 **40 热**；伤害倍率 = 1 + (热量−40)/80，满热 **×2.0**，释放后热量归零 |
| **代价** | 生命即资源；没有安全阀；逼走位时容易把自己耗死 |
| **质变点** | 把热量条从「资源条」改成「伤害倍率条」。玩家行为从「打满就放」变成**「现在打还是再等」**——这是整个游戏节奏的反转 |
| **招牌组合** | 多重连刺（高频根命中存热）+ 破韧重装（破防）+ 蓄力重斩 III（超限核爆）+ 蓄势派生 |
| **爽感曲线** | 存热 → 破防 → 时停 → 一发 |
| **待定数值** | 生命消耗比例、倍率上限、受击热量流失、脱战清空时间（见单核心方案 §八） |

> 这条核心是 HTML 4.6 里「热量超限转伤害仅特定核心启用」的唯一实现者，**建议保留为官方口径**，不要另造一个核心抢这个身份。

### 2.2 节拍核心 · 连奏（主：连奏 / 副：核爆）

| 项 | 内容 |
|---|---|
| **改写规则 1** | **搓招**：**连段跨键续接**——攻击序列的三段连击可在 0.5s 内被另一键续接，段数不归零（攻一段 → 装 → 攻二段 → 攻三段）；连段窗口 0.35s → 0.55s |
| **改写规则 2** | **触发**：三键**交替**时中继效率 ×1.2；连续同键 ×0.8 |
| **代价** | 单键无脑连打被明确惩罚；操作复杂度上升，需要数拍子 |
| **质变点** | 把「连段」从**单插件自带动作**升级成**跨键节奏游戏**。攻击序列从「一棵树」变成「整台机器的主旋律」 |
| **招牌组合** | 多重连刺（攻）+ 雷矢链刺（装）+ 双重释放；中继 连击链动 II（2 分支）→ 等离子弹射 / 爆震跃击 |
| **爽感曲线** | 切键 → 续段 → 中继齐发 → 满屏数字 |
| **风险** | 需要连段计数 UI + 拍点提示，否则玩家感知不到「我踩对了」 |

### 2.3 织网核心 · 蜘蛛（主：织网 / 副：锁链）

| 项 | 内容 |
|---|---|
| **改写规则 1** | **树结构**：中继接口 **+1**（一拖 3 → 一拖 4） |
| **改写规则 2** | **树结构**：**赋能可附着到中继插件上**，作用于该中继下方**全部子技能**（这是「词缀 → 分支词缀」的质变） |
| **代价** | 分支赋能的载荷 = 单词缀载荷 **× 子技能数**；中继效率全局 **−0.2** |
| **质变点** | 一颗词缀从「强化一个技能」变成「强化一条分支」。这是本作最接近哈迪斯双神祝福的体验——**一个决定放大整棵树** |
| **招牌组合** | 重力轰拳（失衡源）+ 失衡爆破 III（3→4 分支）+ 断稳 + 状态催化 + 蓄力重斩/铭痕裂击/爆震跃击/索锚打击 |
| **爽感曲线** | 建条 → 踩住 → 四路齐发 |
| **注意** | HTML 4.3 明确写过「赋能作用于下方所有技能」是**魔法工艺的机制，非本作设定**。所以它只能作为**织网核心的专属特权**存在，绝不能变成常态规则 |

### 2.4 备选核心：钟摆 · 悖论（自动化）——建议放到后期

现有方案「释放后自动切下一键 + 超限耗血」会把玩家变成观众。动作游戏里「自动战斗」的爽感寿命极短，且与本作「搓招」支柱冲突。建议：
- 降级为**挑战/彩蛋核心**（高难解锁、不计入主流程平衡）；
- 或改写成「**拍点自动补键**」——玩家按错拍时自动补一个弱化版（效率 ×0.5），保留参与感。

### 2.5 备选核心：指挥 · 战术（自由编排）——现方案会拆掉支柱

现方案「允许行为直连 + 允许本树引用自产状态」等于**同时废掉中继与跨树协作**，两根本作支柱直接消失。不建议原样保留。

**改造建议「孤树核心」**：
- 允许本树引用**自产状态**，但该状态**对其他树不可见**；
- 该树中继效率 ×0.6，且该树不能再引用他树状态。
- 结果：一棵**自给自足的孤岛树**，换来装配自由，代价是效率与协作。这才是有取舍的核心。

### 2.6 三核边界校验

| 同一插件 | 熔炉 | 节拍 | 织网 | 玩法是否真的不同 |
|---|---|---|---|---|
| 多重连刺 | 积热引擎（存满再放） | 切键枢纽（续段锚点） | 多段喂触发（分支点火器） | ✅ 三种身份 |
| 蓄力重斩 | 超限首选（核爆本体） | 节奏破坏者（蓄力打断切键） | 分支齐发的一员 | ✅ |
| 重力轰拳 | 低收益（慢、少段） | 中收益 | 唯一失衡源 → 必带 | ✅ |
| 浮游机炮 | 持续存热 | 常驻填充 | 常驻 + 殉爆接力核心 | ✅ |

> 判据成立：同一插件在三核下**收益结构不同**，不是「+30% 变成 +40%」。

### 3.3 T2 跨插件共鸣（6 组）

| # | 组合 | 涌现效果 | 代价/门槛 |
|---|---|---|---|
| 1 | 机群扩编（召唤）× 殉爆接力（中继 1.5–1.95） | **轰炸循环**：召唤物到期即炸，数量越多炸得越密 | 召唤池需补到 ≥3 插件 |
| 2 | 超频狂暴（自伤换攻速）× 殉爆接力 | **自杀轰炸**：短命高攻速召唤物，炸得又快又痛 | 持续扣血 |
| 3 | 断稳 × 失衡爆破 III | **锁死窗口**：失衡条衰减暂停 1.5s，多喂一轮 1.6 效率触发 | 只对失衡目标，Boss 抗性递进 |
| 4 | 状态催化（建条）× 状态凝滞（保条） | **条不回落**：累计更快、衰减更慢 | 需两条词缀分附不同插件 |
| 5 | 热量节流 × 熔炉核心 | **反向陷阱**：节流降低积热，在熔炉下是**负收益** | 设计上有意义：教会玩家「核心会改变词缀价值」 |
| 6 | 公转（下游绕上游）× 织网（分支赋能） | **常驻卫星领域**：触发型技能变成被动光环 | 载荷高，且需树内下游 |

> 第 5 组特别值得保留：**同一个词缀在不同核心下价值反转**，这是最便宜的「转模」教学，不需要新资产。

### 3.4 T3 核心共鸣（核心重新定义词缀）

| 核心 | 被重定义的关键词缀 | 新含义 |
|---|---|---|
| 熔炉 | 热量节流 | 从「省热」变成「存热效率」——负收益或需要重新理解 |
| 熔炉 | 精准校准 / 致命打击 | 热量转伤与暴击乘区叠加，收益非线性放大 |
| 节拍 | 双重释放 | 两次释放是否都算「切键」——决定它是否成为节奏核心 |
| 节拍 | 蓄势派生 | 蓄力会打断切键节奏，从增益变成节奏负担 |
| 织网 | 范围扩大 | 附在中继上 = 全分支范围 +30%，单词缀价值翻数倍 |
| 织网 | 状态催化 | 附在中继上 = 全分支建条加速，状态流成型速度翻倍 |

### 3.5 转模纪律（四条）

1. 共鸣必须**是已有规则的交叉**，不新增系统。
2. 每组共鸣必须能**一句话说清**（说不清就是数值堆叠）。
3. 每组共鸣必须有**明确代价或门槛**（载荷 / 状态前置 / 稀有度）。
4. **禁止「组合即无敌」**：任何共鸣都要有反制场景（单体 / Boss 免控 / 无状态目标）。

## 五、流派与 BD 配方

### 5.1 流派分类法

**流派 = 状态轴 × 输出载体 × 节奏**

- 状态轴：燃烧 / 感电 / 侵蚀（含电蚀）/ 失衡 / 无状态（纯物理）
- 载体：近战 / 远程 / 召唤
- 节奏：连打 / 蓄爆 / 自动

理论 5×3×3 = 45 种，**当前内容只支撑 8 种**（见下）。这就是 §0.2 缺口的直接后果。

### 5.2 八套 BD 配方

> 载荷为估算（按主表档位相加），用于判断是否塞得进 300。超限不占载荷。

#### BD-1 熔炉 · 存热核爆（熔炉核心 / 主核爆 副赌命）

| 槽 | 内容 | 载荷 |
|---|---|---|
| 攻击树 | 根 **多重连刺 II** + 精准校准 + 致命打击 | 40 + 18 + 18 = 76 |
| 重装树 | 根 **破韧重装 II** + 蓄势派生 → 中继 连击链动 II（2 分支）→ 爆震跃击 I / 索锚打击 I | 40 + 20 + 10 + 50 = 120 |
| 超限 | **蓄力重斩 III** | 0 |
| 合计 | | **196 / 300** |

- **循环**：连刺存热到 120（不衰减）→ 破韧进破防窗口 → 耗血放超限 → 热量超限转伤 → 一发。
- **爽点**：忍住不放的张力 + 时停大数字。
- **弱点**：每次超限掉 15% 血；被逼走位断节奏；破防窗口短。
- **成型难度**：中（核心 + 两个 II 即可跑）。

#### BD-2 节拍 · 切键连奏（节拍核心 / 主连奏）

| 槽 | 内容 | 载荷 |
|---|---|---|
| 攻击树 | 根 **多重连刺 II** + 双重释放 | 40 + 20 = 60 |
| 重装树 | 根 **雷矢链刺 II** + 雷引 → 中继 连击链动 II → 等离子弹射 I | 40 + 18 + 10 + 25 = 93 |
| 超限 | **爆震跃击 III** | 0 |
| 合计 | | **153 / 300** |

- **循环**：攻一段 → 装 → 攻二段（续段不归零）→ 攻三段；每次切键中继效率 ×1.2。
- **爽点**：无缝、满屏数字。
- **弱点**：同键连打 ×0.8；需要节奏感。
- **成型难度**：低（载荷最轻，适合新手第一套）。

#### BD-3 织网 · 失衡锁链（织网核心 / 主锁链 副织网）

| 槽 | 内容 | 载荷 |
|---|---|---|
| 攻击树 | 根 **重力轰拳 II** + 状态催化（加速失衡条） | 40 + 15 = 55 |
| 重装树 | 根 **破韧重装 II** + 断稳 → 中继 **失衡爆破 III**（3 分支 → 织网 +1 = 4）→ 蓄力重斩 I / 铭痕裂击 I / 爆震跃击 I / 索锚打击 I | 40 + 18 + 20 + 100 = 178 |
| 超限 | **蓄力重斩 III**（与子技能 I 不冲突，属不同稀有度版本） | 0 |
| 合计 | | **233 / 300** |

- **循环**：轰拳建失衡条 → 断稳踩住（衰减暂停 1.5s）→ 四路 1.6 效率齐发。
- **爽点**：敌人被钉住，四路同时命中。
- **弱点**：分支流吃载荷（233 已接近上限）；Boss 韧段高、失衡抗性递进。
- **注意**：「一插件一用」按插件系列判定，同系列不同稀有度是否可同时装配需拍板（见 §七-9）。

#### BD-4 电网 · 感电侵蚀（无核心 / 织网更佳）

| 槽 | 内容 | 载荷 |
|---|---|---|
| 攻击树 | 根 **等离子弹射 II** + 散射 + 电磁链锁 | 40 + 20 + 22 = 82 |
| 重装树 | 根 **侵蚀爪刃 II** + 雷引 → 中继 感电回路（0.90）→ 蚀染铳击 I + 状态传染 | 40 + 18 + 15 + 25 + 18 = 116 |
| 超限 | **爆震跃击 III** | 0 |
| 合计 | | **198 / 300** |

- **状态链**：感电 + 侵蚀 → **电蚀**升级（上限 +1、出伤加快）。
- **爽点**：屏幕一张电网，群体持续掉血。
- **弱点**：单体弱；需要两种状态都建条。

#### BD-5 燃烧双线（熔炉或织网）

| 线 | 内容 | 载荷 |
|---|---|---|
| **持续线** | 攻击树：炽燃斩 II + 助燃 + 状态凝滞；重装树：灼芯回路（0.84，须放**非燃烧树**）→ 多重连刺 I + 状态催化 | ≈ 40+16+15 + 15+25+15 = 126 |
| **爆发线** | 炽燃斩 II + 等离子弹射（感电）→ **爆燃**反应；不给助燃 | ≈ 40+40 = 80 |
| 超限 | 蓄力重斩 III / 蚀染铳击 III | 0 |

- **设计要点**：助燃（维持燃烧）与爆燃（消耗燃烧）**天然互斥**——玩家必须选「看着它烧」还是「炸它一次」。这是本作最干净的一条流派分叉。
- **弱点**：燃烧只有 1 个源，两条线共用同一个插件 → 无法在一局内同时做两条。

#### BD-6 召唤引信（**当前不可成立**，需补内容）

| 槽 | 内容 | 状态 |
|---|---|---|
| 攻击树 | 浮游机炮 II + 机群扩编 | 可 |
| 重装树 | **缺召唤插件** + 超频狂暴 | 阻塞 |
| 超限 | **缺召唤插件** | 阻塞 |
| 中继 | 殉爆接力 III（2 分支，1.95） | 可 |

**补件建议**：加 2 个召唤插件——「定点炮台」（原地持续射击，适合常驻）与「自爆无人机」（短命高伤，专为殉爆接力设计）。补完这条流派才能成立。

#### BD-7 标记处决（**当前不可成立**，标记无源）

| 槽 | 内容 | 状态 |
|---|---|---|

#### BD-8 牵引洗地（无核心）

| 超限 | **破韧重装 III** | 0 |

- **弱点**：对单体 Boss 收益低；聚怪需要敌人配合。

### 5.3 载荷预算规律

| 规律 | 说明 |
|---|---|
| 一棵树 120–150 | 根 II（40）+ 中继（10–20）+ 子 I（25）+ 双词缀（≈35） |
| 两棵树 ≈ 240–280 | 300 上限基本卡住「两棵完整树」 |
| **分支流的代价是载荷，不是效率** | 与「多分支不摊薄效率」呼应：四分支多付 75 载荷 |
| 超限零载荷 | 所以超限永远是「白送的一发」→ 强度要靠核心/热量控制 |

## 六、成型曲线与反爽点

### 6.1 三段成型

| 阶段 | 玩家手里有什么 | 爽点来源 | 设计任务 |
|---|---|---|---|
| **前期** | 1 棵树 + 1 中继 + 1 超限，无核心 | 单树连段的即时反馈 | 保证「一棵树也能爽」，不要逼玩家先凑齐两棵树 |
| **中期** | 两棵树 + 核心 + 2–3 词缀 | 跨树状态协作、核心改写规则 | 第一次「啊，原来可以这样」 |
| **后期** | 完整 BD + 三核切换 | 转模共鸣、极限载荷调配 | 让玩家能自己发现 T1/T2 共鸣 |

### 6.2 反爽点清单（必须提前处理）

| 反爽点 | 后果 | 处理方向 |
|---|---|---|
| 中继 0.5s CD + 高频命中 | 玩家觉得「打了没反应」 | 未触发时给明确视觉反馈（灰掉的分支图标） |
| 召唤/领域视觉噪音 | 看不清敌人和自己的位置 | 召唤物半透明、轮廓描边、敌我色分离 |
| 蓄力被断 | 核爆流挫败感强 | 蓄力阶段给霸体或分段存档 |
| Boss 免控 | 锁链流直接失效 | 免控时给「破韧转伤」替代收益 |
| 自动触发因果不可见 | 玩家不知道为什么伤害出现 | 触发时画一条 0.2s 的连接线 |
| 熔炉耗血无出口 | 赌命流劝退 | 保留至少一条回血/护盾路径（词缀或核心副效果） |
