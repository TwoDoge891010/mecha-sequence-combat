| 项 | 值 |

| 韧段 | 杂兵 1 / 精英 3 / Boss 8；削韧 攻击 1 / 重装 3 / 超限 6；破防窗口约 2s，易伤 ×1.3 |
| 状态时长 | 燃烧 3s / 感电 5s / 侵蚀 6s / 电蚀 4s / 失衡 2s / 标记 8s |
| 暴击 | 基础暴击率 0%，倍率 ×3.0，靠「精准校准 / 致命打击」买 |

> 以上只是口径摘要，**具体到每个技能的三槽数值只以 xlsx 为准**。

### 4.3 已对齐的设计方向（勿再推翻）

- 流派 = **「核心（锚）× 招牌组合」涌现**，不预设官方流派清单（参考哈迪斯武器形态 / 暖雪宗门）。
- 核心必须是**机制质变**，不是 ±X% 数值。
- 跨流派要有**化学反应层**（两条条件共存触发特殊效果，类似哈迪斯的 Duo Boons）。
- Boss **动作第一、BD 为加分**：不会 BD 也能靠读前摇通关，韧段破防是额外输出窗口而非硬门槛。
- 赋能不触发下游（触发是中继专属职责）；中继条件只能引用**另一棵树**制造的状态。
