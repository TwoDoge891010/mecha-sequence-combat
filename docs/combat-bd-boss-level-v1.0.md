## 1. 战斗设计细化

### 1.1 战斗循环总览（三层资源 + 一条决策链）

```
三键输入 ──► 两棵树（攻击序列 / 重装序列）编程输出
     │
     ├─ 资源① 状态层：命中累计状态条 → 满条施加状态 → 共存反应（爆燃/电蚀，自动）
     │                          └─ 主动引爆（侵蚀/标记，插件触发）
     ├─ 资源② 热量层：根行为插件命中积热 → 超限释放耗热（收割 + 削韧）
     └─ 资源③ 韧段层：攻击削韧 → 韧段见底 → 破防窗口（控制全效 / 易伤增增）
```

一条完整决策链：**用攻击序列铺状态 + 攒热 → 重装序列卡 CD 打控制/高倍率中继 → 超限释放在破防窗口收割（消耗状态 + 削韧）。** 三层资源互不重叠，但共享同一个「打点时机」——破防窗口是三者同时兑现的高点。

### 1.2 热量经济（资源②，细化）

既有真值：热量只由**根行为插件**结算；上限 120；超限耗热 65/70/75 视插件定。

| 项目 | 值 | 口径 |
| --- | --- | --- |
| 攻击序列根插件积热 | 2/2/2（炽燃斩三段 2+3+4 累计 9） | `[已定]` 频次高、单次低 |
| 重装序列根插件热产 | 22（全插件统一） | `[已定]` 单次高、受 CD 约束 |
| 超限释放耗热 | 65（炽燃）/70（重力）/75（涡刃·等离子·蚀染·浮游） | `[已定]` |
| 热量超限转伤害 | 仅「熔炉核心」启用 | `[已定]` 非通用 |
| 积热效率引导 | 攻击序列「快而散」、重装序列「慢而整」、超限「整口吞」 | `[初稿]` 三键手感差异口径 |

设计含义：热量是「给超限释放这个单插件终结技定价」的货币，任何不投超限的 BD 会多出闲置热量——「熔炉核心」正是用来把闲置热量变现，使热量从通用资源升级为流派稀缺筹码。

### 1.3 状态三段结算（资源①，细化）

既有规则：命中累计状态值 → 满条施加 → 反应（爆燃/电蚀自动）→ 主动引爆（独立）。6 状态 + 2 反应。累计只看「是否携带状态施加」，不看行为出处。

| 段 | 机制 | BD 角色 |
| --- | --- | --- |
| ① 制造 | 命中推进状态条，条满施加 | 决定「你能喂给跨树中继什么弹药」 |
| ② 存续 | 施加后的 DoT / 减益 / 控制持续 | 制造持续收益或控制窗口 |
| ③ 引爆/反应 | 共存反应自动兑、或插件主动引爆 | 把「积累」一次性兑换成爆发 |

六状态分工：

| 状态 | BD 定位 | 主制造来源（现状） |
| --- | --- | --- |
| 燃烧 | DoT 持续线 / 爆燃原料 | 炽燃斩（近战/燃烧） |
| 感电 | 减防催化剂 / 反应共享催化剂 | 等离子弹射（远程/感电） |
| 侵蚀 | 可引爆 DoT（叠 3 层）/ 电蚀原料 | 蚀染铳击（远程/侵蚀） |
| 电蚀 | 侵蚀升级态（叠 4 层） | 侵蚀 + 感电共存升级 |
| 失衡 | 控制态，极苛刻中继原料 | 重力轰拳（近战/失衡，II 起） |
| 标记 | 被引爆时兑现暴击加成 | **待补行为来源**（见 §2.6） |

### 1.4 韧段破防循环（资源③，定位降级为「加分」）

既有规则：韧段独立于血量；削韧量累计；韧段见底→破防窗口（控制全效、易伤增伤）；递进抗性防无限控；超限=削韧大招。**本版定位调整：韧段破防是「额外输出窗口」的加分机制，不构成通关硬门槛**（对应 Boss 章「动作为主」）。

| 项目 | 初稿值 | 说明 |
| --- | --- | --- |
| 韧段长度 | 杂兵 1 / 精英 3 / Boss 8 | `[初稿]` |
| 削韧量 | 攻击序列 1 / 重装序列 3 / 超限释放 6 | `[初稿]` |
| 破防窗口 | 约 2.0s（对齐失衡 2s） | 窗口内控制全效 + 易伤 ×1.3 |
| 递进抗性 | 同类控制第 N+1 次所需累积 ×1.3，最多叠 5 | `[初稿]` |

### 1.5 操作节奏与打点

| 输入 | 节奏定位 | 打点要点 |
| --- | --- | --- |
| 攻击序列（无 CD） | 频率骨架，铺状态 + 攒热 | 连段窗口 0.35s |
| 重装序列（根 CD 5–8s） | 节奏重音，挂控制 / 高倍率中继 | 卡 CD 在状态齐全时打 |
| 超限释放（耗热 65–75） | 终结节拍，收割 + 削韧 | 破防窗口内收益最大 |

## 2. 流派设计（锚 × 招牌组合涌现）

### 2.1 设计原则：核心 = 锚，流派 = 涌现

借鉴哈迪斯（武器形态 Aspect）、暖雪（宗门）的做法：

1. **机甲核心 = 锚**：全局唯一、开局/常驻选定，**机制质变**（改变「你玩这局的方式」），不是 ±X% 数值。
2. **流派 ≠ 预设死清单**：流派是「锚 × 招牌组合」自然涌现的。玩家认知是「这局玩 `熔炉 × 引火自焚`」这种「核心 + 招牌 combo」，不是背一张官方流派表。
3. 因此本文不列「官方五大流派」，只给四样东西：**锚清单（§2.2）→ 协同规则（§2.3）→ 招牌组合引导（§2.4）→ 化学反应层（§2.5）**。

### 2.2 锚（机甲核心）清单一览：各自机制质变

| 核心 | 机制质变（改变了你玩这局的哪种方式） | 代价/权衡 | 数值 `[初稿]` | 状态 |
| --- | --- | --- | --- | --- |
| 熔炉·过载 | 超限的经济来源从「攒热」改成「用生命」；闲置热量可变现为伤害 | 换血高风险 | 超限耗 15% 当前生命；热量溢出 `×0.5%/点` 转伤害加成 | 机制成熟 |
| 节拍·连奏 | **重构**：三键切键 = 「节拍点」，连携窗口内切键重置重装根 CD、累计 3 拍触发「自由派生」（额外一击，不占槽不耗热） | 节奏断了（超窗/重复同键）全部清空 | 窗口 3s；每 3 拍 1 次派生 | **本次重构** |
| 织网·蜘蛛 | 中继接口 +1（一拖 3 → 4），把「点」铺成「网」 | 中继效率全局 −0.3 | 接口 +1；效率 −0.3 | 机制成熟 |
| 钟摆·悖论 | 手动三键切 → 系统自动切入，释放双手去走位 | 失去精确打点自由 | 攻击序列连招后自动接重装根 | 机制成熟 |
| 指挥·战术 | 突破两条装配铁律（必须有中继 / 跨树协作），换来单树编排自由 | 免中继 ×0.6、本树引用 ×0.8 双惩罚 | 免中继衔接 ×0.6；本树引用 ×0.8 | 机制成熟 |

> 说明：原 v1.0 里「节拍·连奏」是「三键各用一次 +30%、积热 +50%」的纯数值，不符合「机制质变」原则，本版重构为「节拍点切键派生」。其余 4 核已是机制质变，保留。

### 2.3 协同规则（可学习口诀）

对应哈迪斯「百分比放慢重击、固定伤害放快攻」，把本系统的协同规则总结成玩家能背的口诀：

1. **状态是弹药，中继当扳机**：行为铺状态，中继消费他树状态（跨树铁律）。
2. **轻积重耗**：攻击序列高频铺热，重装/超限低频大额。
3. **引爆清空持续**：助燃（持续线）与临界引爆（爆发线）互斥。
4. **越苛刻越暴力**：触发条件越难的中继，效率倍率越高（殉爆/失衡 > 致命引信 > 灼芯/感电 > 连击 > 走时）。
5. **召唤不攒状态，只当引信**：召唤路线与状态路线是两条轨道，靠「销毁」触发。
6. **暴击要主动买，标记要有人造**：基础暴击 0%，需精准校准（率）+ 致命打击（倍）+ 标记来源投入。

### 2.4 招牌组合（= Duo，引导示例，非死清单）

每个核心配 1 个「一句话 build」作引导入口；玩家可自由偏离：

| 招牌名 | 核心 | 关键插件 | 一句话原理 | 成型信号 |
| --- | --- | --- | --- | --- |
| 引火自焚 | 熔炉 | 炽燃斩 + 灼芯回路 + 临界引爆 | 铺火 → 爆燃清场 → 超限用命收割，溢出热转伤 | 一个超限清半屏 |
| 三连派生 | 节拍 | 三色行为 + 蓄势派生 | 三键轮切吃自由派生，重置重装 CD 连续打重音 | 重装序列连发不停 |
| 殉爆蜘蛛网 | 织网 | 浮游机炮 + 殉爆接力 + 走时回路 | 铺场压数量 → 销毁连环爆 | 满屏浮游炮 + 连爆 |
| 走时自动炮 | 钟摆 | 走时回路 + 蓄能齐射 + 连击链动 | 全自动触发链，站桩只躲招 | 不按键也持续出伤 |
| 单树长链 | 指挥 | 全系行为 + 公转（日月轨道） | 免中继堆深链，单树干到底 | 一颗树上 5+ 节点 |

### 2.5 跨流派化学反应层（兼容 + 奇妙反应）

流派之间**不互斥**：所有核心共享同一张「状态网络 + 反应网络」，混搭不同状态线 / 核心 + 状态，即可拼出 Duo 式化学反应。规则 = **两条条件共存即触发**（类似哈迪斯 Duo Boons「两个神都在才触发」）。

**A 层 · 状态反应 `[已定]`**：爆燃 = 燃烧 + 感电；电蚀 = 侵蚀 + 感电。任意两个状态制造者都能凑出，是天然跨流派协同。

**B 层 · 核心 × 状态 化学反应 `[初稿]`**（种子，供玩家拼条件）：

| 化学反应 | 触发条件 | 效果 | 拼法示例 |
| --- | --- | --- | --- |
| 引燃收割 | 熔炉 + 超限命中燃烧敌人 | 燃烧剩余 DoT 提前结算，并计入热量溢出增伤 | 熔炉 × 燃烧线 |
| 导电蜂群 | 织网 + 浮游炮间存在感电敌人 | 浮游炮间传导感电，范围内敌人共享减防 | 织网 × 感电线 |
| 破防派生 | 节拍 + 自由派生命中失衡敌人 | 派生必触发失衡爆破，并重置失衡条再触发 | 节拍 × 控制线 |
| 溶血潮汐 | 熔炉 + 耗命超限命中带侵蚀敌人 | 把侵蚀层数转为等额回复（以血养血） | 熔炉 × 侵蚀线 |

> 化学反应只给「规则与种子」，不预设死组合——玩家把两条条件线拼起来即触发，是「兼容 + 奇妙反应」的落点。更多种子可在原型验证后追加。

### 2.6 BD 断点清单（取舍点）

| 断点 | 取舍 |
| --- | --- |
| 整装载荷 300 | 钱有限：投行为 / 投中继 / 投赋能 |
| 每行为插件 ≤ 2 赋能 | 词缀位稀缺 |
| 散射 ↔ 双重释放 | 两套多重散布不叠做 |
| 环绕 ↔ 强行追踪 | 轨道自转 vs 长距索敌 |
| 机群扩编 ↔ 超频狂暴 | 求稳 vs 求爆 |
| 助燃 ↔ 临界引爆 | 持续线 vs 爆发线 |
| 状态催化 ↔ 断稳 | 提前建条 vs 踩住现条 |
| 跨树铁律 | 中继只能引用他树状态 |
| 稀有度/分支平衡 | 加分支则效率增量收缩 |
| 标记制造来源 | **缺口：需补一个标记系行为/赋能** |

## 3. Boss 原型设计（动作为主，BD 为加分）

### 3.1 设计原则

1. **动作第一**：重心在招式辨识、前摇反应、走位躲招、抓后摇输出。Boss 是「打出来的」，不是「算出来的」。
2. **BD 是加分**：状态 / 中继 / 韧段不构成通关硬门槛，只决定「会 BD 的玩家打得更快更爽」。
3. **韧段降级**：破防窗口 = 额外输出窗口（非唯一），见 §1.4。
4. **状态是打点增益**：状态对 Boss 生效但弱化（见下表），不逼玩家换流派。

### 3.2 Boss「晶枢守卫 · 棘枢」

> 定位：灰域霸主晶化改造的魔女战士，灰域核心入口的第一道门神，验证动作为主 + BD 加分的 Boss。`[初稿]`

| 基本信息 | 内容 |
| --- | --- |
| 背景 | 曾与主角同源的魔女，被灰域霸主晶化改造，保留高阶意识却失去自我，「棘罪」失控结局的具象化 |
| 体型/血量 | 中型 Boss `[初稿]` |
| 战斗节奏 | 中速，靠「读前摇 + 抓后摇」过关 |

**核心动作循环**（动作层，本 Boss 的主体）：

| 招式 | 前摇 | 判定 | 规避 | 后摇/惩罚 |
| --- | --- | --- | --- | --- |
| 横扫晶刃 | 0.6s 抬臂 | 近身扇形横扫带击退 | 绕后 / 后撤 | 收招 0.8s，可输出 |
| 晶簇钉弹 | 0.5s 亮刺 | 扇形弹幕 ×3 波 | 横向侧移 | 波间 0.5s 间隙 |
| 棘罪脉冲 | 1.0s 核心聚光 | 周身范围 DoT | 离开核心圈 | 聚光结束 0.7s 硬直 |
| 突进劈斩 | 0.4s 俯身 | 直线突进 + 下劈 | 侧闪 | 劈空 1.0s 大硬直 |
| 召唤晶簇 | 0.8s 挥手 | 召 2–3 只晶簇杂兵 | 爆燃/范围清场 | 召唤时背对玩家 |

**三阶段（动作模式变化，不是数值门）**：

| 阶段 | 名称 | 动作变化 |
| --- | --- | --- |
| P1 | 晶壳（100–70%） | 招式速度偏慢，晶壳减伤 30%（非 50%，避免拖沓）；主用横扫 + 钉弹 |
| P2 | 棘罪（70–35%） | 晶壳破裂，新增「突进劈斩」，前摇缩短 20%，进入高强度对拼 |
| P3 | 暴走（≤35%） | 全招式衔接加快、弹幕加密，但「棘罪脉冲」后硬直更长 → 高风险高回报 |

**BD 加分点**（不构成门槛，只优化效率）：

| 状态/机制 | 对 Boss 的加分效果 |
| --- | --- |
| 燃烧 | 晶壳态持续 DoT 照常跳，变相削弱减伤 |
| 感电 | 减防生效，放大窗口输出 |
| 失衡 | 破防窗口内控制全效，创造额外输出窗口 |
| 超限释放 | 大额削韧，加速踩出破防窗口 |
| 爆燃反应 | 清晶簇杂兵的最快解 |

> 玩家**不依赖任何状态也能过**（靠动作躲招 + 基础输出），状态是「打得快」的杠杆，不是「过不过」的钥匙。

### 3.3 Boss 2（终极 · 框架）「灰域霸主」

> 盘踞灰域的强横晶化个体，接近 Azul_01 完全体，魔女「棘罪」阴影根源（`[已定]` 世界观）。只给方向框架。`[初稿]`

| 维度 | 框架 |
| --- | --- |
| 定位 | 终章 Boss，三形态（灰域领主 → 棘罪真身 → 准 Azul_01） |
| 动作主核 | 更高密度的弹幕 + 需精确读前摇的连段；阶段内动作模式切换 |
| BD 加分方向 | 不同形态对部分状态更敏感（作为「打得快」的提示，非门槛） |
| 情感镜像 | 终战呼应「棘罪 = 力量与代价一体」，Boss 失控即主角可能的结局 |

## 4. 关卡设置

### 4.1 结构总览（Hub + 四区域 + 关底）

```
铸炉基地（Hub）
   ├─ 区域1 灰域边缘（教学：近战 + 燃烧 + 首个中继）
   ├─ 区域2 蚀染荒原（教学：远程 + 侵蚀 + 状态累计条）
```
